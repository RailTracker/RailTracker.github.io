# Portfolio

Static portfolio and tic-tac-toe site hosted on GitHub Pages. No build step or package installation is required.

To preview locally, run `python -m http.server` from the repository root and open http://localhost:8000/. Edit `index.html`, `assets/css/style.css`, and the files under `projects/` and `assets/js/` directly.

The `.nojekyll` file tells GitHub Pages to publish the static files without Jekyll. `CNAME` preserves the custom domain when deploying from the repository.
